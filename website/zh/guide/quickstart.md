# 快速开始

三步就能用上。程序会自动启动本地服务并打开主界面,不需要任何手动配置。

## 1. 下载安装包

到本项目 **Releases** 页面下载最新的安装包(`.exe`),双击完成安装。

::: tip 提示
桌面应用打包后没有数字签名,首次运行可能触发 Windows SmartScreen 提示。点击"更多信息" → "仍要运行"即可,详见[常见问题](./faq)。
:::

## 2. 启动程序

安装完成后,双击桌面上的 **DeepSeek Harness** 图标。

- 无需安装 Node.js、pnpm 或任何命令行工具
- 支持安装在包含中文的路径下
- 程序常驻系统托盘,关闭窗口不会退出程序

## 3. 设置 API Key

首次启动会弹出引导窗口,填写你的 DeepSeek API Key:

1. 打开 [platform.deepseek.com](https://platform.deepseek.com),注册并登录
2. 在 **API Keys** 页面点击"创建",得到一个形如 `sk-...` 的 Key
3. 把 Key 粘贴进引导窗口,点击"开始使用",主界面自动打开

> 你的 Key 只会写在这台电脑上,不会上传到任何地方。程序自动启动本地服务并打开主界面,之后无需任何手动操作。

## 安装要求

- Windows 10 / 11(64 位)
- 无需安装 Node.js、pnpm 或任何命令行工具
- 支持安装在包含中文的路径下
