# 常见问题

## 杀毒软件报毒、SmartScreen 提示怎么办?

桌面应用打包后没有数字签名,第一次运行时 Windows SmartScreen 可能会提示"Windows 已保护你的电脑",部分杀毒软件也可能误报。这是打包软件的常见情况,不代表程序有问题。

**SmartScreen 提示**

点击"**更多信息**" → "**仍要运行**"即可。

**Windows Defender 排除**

1. 打开"病毒和威胁防护"
2. 进入"排除项" → "添加或删除排除项"
3. "添加排除项" → 选择安装目录或程序文件

**360 安全卫士**

木马查杀 → 信任区 → 添加信任目录,选择安装目录。

**火绒安全**

防护中心 → 病毒防护 → 信任区 → 添加文件/目录,选择安装目录。

**腾讯电脑管家**

病毒查杀 → 信任区,添加安装目录。

## 能安装在中文路径吗?

可以。桌面版不依赖命令行脚本,装在带中文的路径(比如 `软件\DeepSeek Harness`)下也能正常运行。

## 端口被占用怎么办?

不用担心。服务监听端口由系统自动分配(**端口 0**),启动时系统会挑一个空闲端口,天然不会和 3080 或其他程序冲突,也不需要手动配置。

## 关掉窗口后程序为什么还在?

关闭窗口默认是**最小化到托盘**,程序仍在后台运行,这是有意设计——服务保持在线,随时可以唤出。从托盘菜单里选择"**退出**"才会完全结束程序。

## API Key 存在哪里?

你的 DeepSeek API Key 只会保存在**这台电脑上**:

- Key 通过引导窗口输入后加密保存在本机
- 不会上传到任何地方,也不会被发送到任何服务器
- 数据目录位于 `%USERPROFILE%\.dsh`

如果你更换电脑或想重新配置,卸载重装后重新运行引导即可。

## 需要付费吗?

软件本身是**免费开源项目**,但调用 DeepSeek 的 API 由官方**按量计费**。

当前参考价(每百万 tokens):deepseek-v4-flash 输入 $0.14、输出 $0.28;deepseek-v4-pro 输入 $0.435、输出 $0.87;命中缓存时输入价格要低得多。

具体价格以 [官方价格页](https://api-docs.deepseek.com/quick_start/pricing) 为准。2026-08-16 起官方改为峰谷计价。
